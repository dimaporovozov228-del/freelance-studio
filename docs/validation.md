# Проверка 19 ноября 2026

Окружение: Windows, Python 3.13.18, openpyxl 3.1.5, et-xmlfile 2.0.0. Python и uv подготовлены в соседней рабочей папке; `.venv` локален и в архив поставки не входит.

Выполнены:

- `python -m unittest discover -s tests -v`: 10 тестов, OK. Полный вывод: `demo-results/tests.txt`.
- CLI с CSV: 7 входных, 4 принятых, 3 отклонённых, 3 сопоставленных, 1 неизвестный SKU; сумма 3851.00.
- CLI-движок с синтетическими XLSX: тот же результат, отчёты в `demo-results/xlsx-input/`.
- Офлайн-оценка трёх синтетических заказов: результаты в `demo-results/jobs-ranked.json`.
- HTTP-интеграция: GET формы 200, POST с файлами 200 и ZIP с отчётом, POST без токена 403. Сервер теста остановлен автоматически.
- Регрессия зависания: открытое соединение без HTTP-запроса больше не блокирует загрузку страницы. Используется ThreadingHTTPServer, ожидание данных соединения ограничено 15 секундами. Рабочий сервер перезапущен, GET вернул 200.

Не проверено: визуальный вид в браузере, Excel Desktop, Linux/macOS и Python 3.11 (для двух версий подготовлен CI), нагрузка на лимитах, реальные клиентские данные и внешние площадки. CI ещё не запускался на GitHub. Спецификации API+БД и workflow не являются готовыми приложениями.
