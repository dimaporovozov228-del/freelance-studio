# Рабочая схема студии

Владелец общается с клиентом, определяет бюджет и подписывает договорённости. ChatGPT помогает разобрать задачу; Codex готовит код и проверки. Обещания, доступы, оплата и финальная приёмка остаются у человека.

Для каждой задачи фиксируем: проблему, разрешённые данные, вход/выход, критерии приёмки, ограничения, исключения, этапы, стоимость и порядок изменений. До оценки получаем обезличенный пример и проверяем сложные места коротким прототипом.

Цикл: ручной отбор → уточнение → письменный объём → реализация → проверки → демонстрация → приёмка → инструкции и согласованная поддержка. Не публикуем клиентские данные и код без согласия.

Портфолио сейчас: работающие локальные демопроекты Sheet Studio и Order Desk API, спецификация workflow и каркас офлайн-оценки заказов. Можно показывать исходники, тесты и синтетические результаты. Нельзя выдавать эти данные за коммерческие кейсы, отзывы или подтверждённую экономию клиента. Доход и доступность площадок не гарантируются и здесь не оценивались.

Перед первым предложением: прогнать файлы потенциального клиента локально после разрешения; проверить схему/объём/валюты; уточнить политику дублей и сопоставления; перечислить исключения; согласовать поддержку. Проверка доступности регистрации, платежей и правил выбранной площадки — отдельный шаг перед её использованием.
