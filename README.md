## Быстрый старт

Нужен Python 3.11+. Команды из корня этого репозитория, Windows PowerShell:

```powershell
py -m venv .venv
.venv/Scripts/python.exe -m pip install -e .
.venv/Scripts/python.exe -m studio.cli examples/orders.csv examples/catalog.csv --output reports
.venv/Scripts/python.exe -m studio.web
```

При первом запуске выполните все команды. Если окружение уже установлено, начните с третьей команды.
Откройте http://127.0.0.1:8765 и выберите два файла из `examples/`. Остановка: Ctrl+C.
Linux/macOS: `python3 -m venv .venv`, затем вместо `.venv/Scripts/python.exe` используйте `.venv/bin/python`.
После установки доступны также команды `sheet-studio` и `job-scout` в окружении.

## Что делает приложение

- Читает UTF-8 CSV с запятой, точкой с запятой или табуляцией; XLSX — активный лист.
- Убирает крайние пробелы, нормализует заголовки и регистр SKU.
- Проверяет обязательные поля, положительное целое количество, неотрицательную цену с максимум двумя десятичными знаками. Поддерживает `1 200,50`.
- Удаляет повторы по `order_id + sku`: сохраняет первую валидную строку. Повторные позиции одного SKU в заказе считаются дублями по принятому правилу демо.
- Сопоставляет SKU точно после нормализации; неоднозначный каталог отклоняет целиком.
- Сохраняет неизвестные SKU со статусом `unmatched`, включает их в общую сумму и журнал замечаний.
- Выгружает `cleaned.csv`, `issues.csv`, `summary.json`, `report.xlsx` с тремя листами.

Заказы: `order_id,sku,customer,quantity,unit_price`. Каталог: `sku,product`.
Денежные расчёты используют Decimal. Валюта не угадывается: все строки должны иметь одну валюту.
В отчёте деньги и числа хранятся текстом, чтобы сохранить точность; это не расчётная Excel-модель.

## Проверка и демонстрация

```powershell
.venv/Scripts/python.exe -m unittest discover -s tests -v
.venv/Scripts/python.exe -m studio.scout examples/jobs.json --output reports/jobs-ranked.json
```

Для полного набора тестов, включая API, предварительно установите `.venv/Scripts/python.exe -m pip install -e ".[api,test]"`. Для тестов только таблиц: `.venv/Scripts/python.exe -m unittest discover -s tests -p test_studio.py -v`.

Пример: 7 входных строк → 4 приняты, 3 отклонены, 1 неизвестный SKU, сумма 3851.00.
Журнал содержит 4 замечания: три отклонения и один неизвестный SKU.
Реальные результаты запуска лежат в `demo-results/`.

## Ограничения

Локальный однопользовательский инструмент; сервер слушает только 127.0.0.1. Не публикуйте его как публичный сервис. Файлы веб-загрузки удаляются после формирования ZIP. Внешних API и платного ИИ нет.
CLI: до 10 MiB на файл и 100000 строк; веб: JSON-запрос до 2 MiB вместе с base64 (~1.5 MiB файлов). Сжатый XLSX может требовать существенно больше памяти: используйте доверенные файлы.
Формулы XLSX не вычисляются; в числовых полях отклоняются. Вывод экранирует префиксы формул. `.xls`, макросы, нечёткое сопоставление, несколько валют и большие объёмы пока не поддержаны.
Пустые строки пропускаются; номер в журнале — порядковый номер непустой записи плюс заголовок, а не гарантированный физический номер строки файла.
Выходная папка должна отличаться от папок исходных данных: файлы отчётов с одинаковыми именами перезаписываются.
